Collection du jeu Dogzie Town

Jet Set

Luxe, prestige et soirées mondaines — la façade brillante de Dogzie Town.

Qui sont-ils ?

Le Jet Set incarne le « bon côté » : vedettes, protecteurs du luxe, figures de la haute société. Ils évoluent entre yachts, jets privés et événements chic.

Rôle dans Dogzie Town

Dans les missions, ils protègent colis précieux, diamants et réputation de la ville. Ils s’opposent souvent aux Criminels, tout en croisant Justiciers et autres factions selon le scénario.

Les textes sur les images PNG peuvent être en anglais — les descriptions HTML ci-dessus font foi pour le site francophone. Ville : Dogzie Town.
